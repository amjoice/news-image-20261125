"The World Today" — one front-page image summing up the world news of
Wednesday 25 November 2026: Ukraine strikes Russian ships in the Gulf of
Finland and off Benghazi, Libya; Houthis hit Riyadh's tallest tower;
Huawei convicted in a US trial; Nvidia slides 7%; tankers hit by mines in
the Strait of Hormuz; fears of a Russian nuclear satellite; a Russian
drone over Poland — plus the day's other stories in the ticker.

## Run it

```sh
python3 render.py        # rebuild entry.png (needs Pillow, build time only)
MAKEFUN_OUTPUT_DIR=out python3 main.py   # writes out/entry.png
```

`main.py` is standard library only and copies the pre-rendered `entry.png`
to the output directory, so both grading runs write identical bytes.
